AI Resume Matcher

AI Resume Matcher is an intelligent job-matching system that analyzes a user’s résumé, compares it against job postings, and generates ranked recommendations based on a custom scoring engine combined with Gemini-powered reasoning.

This project uses a hybrid approach:

Deterministic scoring (tech stack match, seniority fit, domain relevance)

LLM reasoning (Gemini explanations of why each job is a match)

The result is a fast, scalable, and highly interpretable job-matching experience.

🚀 Features
🔍 Resume Parsing

Accepts user résumé text (or pasted input)

Extracts keywords, tech stack, and experience context

📊 Job Matching Engine

Each job is scored using three weighted factors:

Score Type	Weight	Description
Tech Score	40%	Matches job technologies with résumé tech stack
Seniority Score	30%	Compares user experience level vs job requirements
Domain Score	30%	Measures industry fit (healthcare, fintech, SaaS, etc.)

Jobs receive a final_score (0–100) which determines:

Strong Match

Possible Match

Weak Match

🤖 Gemini Integration

Gemini generates:

A natural-language summary of why the job matches

Top 3 alignment points

Potential gaps

Overall recommendation level

Clean JSON output ready for UI rendering

📂 Mock Job Data

50+ mock LinkedIn job postings in JSON format

Simulates real-world job-matching at scale

🖥️ Frontend UI (Next.js + Tailwind)

Displays ranked job results

Match level badges

Explanation cards generated by Gemini

Fast client-side rendering

🧠 How It Works
1. User submits their résumé

Text is analyzed for:

skills

technologies

seniority indicators

industry keywords

2. All jobs in the dataset are scored

Using:

tech_score     = (# matched skills / total skills) * 40
seniority_score = SENIORITY_MAP[job.seniority] * 30
domain_score   = INDUSTRY_MAP[job.industry] * 30
final_score    = tech + seniority + domain

3. Top matching jobs are selected

e.g., top 5–10 by final_score.

4. Gemini receives:

résumé text

job posting

scoring breakdown

and returns:

{
  "title": "...",
  "company": "...",
  "score": 82,
  "match_level": "Strong Match",
  "summary": "...",
  "why_match": "...",
  "top_alignment": ["...", "..."],
  "gaps": ["..."]
}

5. Frontend renders the results

Users see:

score

match level

key reasons

gaps

apply button

⚙️ Setup
1. Clone the repo:
git clone https://github.com/yourusername/ai-resume-matcher.git
cd ai-resume-matcher

2. Install dependencies
npm install

3. Add your Gemini API key

Create .env.local:

GEMINI_API_KEY=your_key_here

4. Run the dev server
npm run dev


Open at http://localhost:3000
